# Story 产品展示

本轮调整继续使用 `/story/`，不作为新风格登记。按用户要求，展示图及前台正文不叠加“合成 / 示意”标签，保持清爽；制作来源在本文记录。

## 制作来源

`scripts/story-screens.mjs` 根据已有软件能力及 `assets/ih/` 的原始软件界面重绘推广用矢量界面，并非逐像素的软件截屏。对话、岗位、文件和记录使用通用的排版内容。没有接入录音、模型、外部数据或遥测；也没有展示未经测试的速度、准确率及真实客户评价。

12 组界面均有独立的浅色和深色版本。桌面画面采用统一金属屏幕边框；手机伴侣使用手机外框；悬浮提词器保留浮窗形态。文案、窗口和设备分别服务于对应功能，不能用手机外框冒充原生移动 App。

| 页面内容 | 画面 key | 重点 |
| --- | --- | --- |
| 首屏 / 听见问题 | conversation | 系统声音、麦克风、转录、问题与建议回答 |
| 回答带上当前场景 | workspace | 独立目标、资料和回答要求 |
| 灵活查看 | phone / prompter | 同一 Wi-Fi 手机查看、桌面悬浮提词 |
| 资料与技能 | materials | 文件列表、资料内容与场景技能 |
| 会后积累 | review | 问题回顾、摘要、改进建议与场景经验 |
| 四步流程 | workspace → materials → conversation → review | 选场景、加资料、实时辅助、复盘 |
| 双路识别 / 回答贴合场景 | conversation / context | 声音来源与相关上下文 |
| 查看方式 / 复盘积累 | devices / review | 桌面与手机、问题回顾 |
| 面试 / 学术 / 会议 / 课程 | conversation / lecture / meeting / course | 每张卡的标题、说明、资料与内容一致 |
| 数据去向 | privacy | 本机保存、回答引擎上下文、可选服务 |

手机伴侣继续描述为同一 Wi-Fi 查看当前问题与回答，不能画成加密云同步。资料、OCR 和语义嵌入仍按原软件边界为可选能力，不以“全量资料都进入上下文”作为宣传。

## 更新流程

1. 编辑生成器中的具体屏幕；正文、文件名及问题答案一起对齐，不只换标题。
2. `npm run screens:build` 生成 `public/story/assets/product-scenes/`。
3. `data-product-screen` 指定图片语义，`data-ih-light` / `data-ih-dark` 指向同一 key 的两种主题，比例保持一致。
4. 在真实浏览器中检查浅色、深色、桌面和窄屏；确认没有文字遮挡、错误画面或误导性的状态。
5. 更新真实首页及画廊截图，执行 `npm run docs:sync`、`npm run check`、`npm run build`。

旧模板的放大镜坐标不适用于重绘界面，已删除。场景卡采用内容决定高度，避免标题、说明与界面被原定高容器裁切。桌面场景切换使用可聚焦的按钮，窄屏保留原生横向滑动。

№ 09{{ 问答 ‖ FAQ }}

{{ 常被问到的。 ‖ Questions people ask. }}

{{ 对方会知道我在用它吗？ ‖ Will the other side know I’m using it? }}

{{ 它不往会议里发任何东西，只在你的 Mac 上听、在你的屏幕或手机上显示。但它不是隐身的：共享整个屏幕时，提词器可能被拍到，见上面“手机伴侣”一节。用不用、怎么用，请遵守会议方的规则。 ‖ It doesn’t send anything into the meeting; it listens on your Mac and shows things on your screen or phone. It isn’t invisible, though: if you share your whole screen, the teleprompter may show up (see “Phone companion” above). Whether and how you use it is up to the rules of the meeting. }}

{{ 支持哪些会议软件？ ‖ Which meeting apps does it work with? }}

{{ 它不挑。线上会议听的是这台 Mac 播放出来的声音，腾讯会议、飞书、钉钉、Zoom、Teams、浏览器里的会议都一样，不需要识别你用的是哪个。 ‖ It doesn’t care. On a call it listens to what your Mac plays, so Zoom, Teams, Google Meet, Webex or a meeting in a browser tab all work the same way. It never needs to detect which one you’re using. }}

{{ 会保存录音吗？ ‖ Does it keep recordings? }}

{{ 不会。声音在本机识别成文字，录音不落盘。保存下来的是转写、回答和纪要，都在你这台 Mac 上。只有你主动选择云端识别并同意之后，音频才会发给对应的服务商。 ‖ No. Audio is turned into text on your Mac and never written to disk. What’s kept is the transcript, the answers and the notes, all on your Mac. Audio only leaves the Mac if you choose cloud recognition and agree to it. }}

{{ 回答是哪里来的？需要什么账号？ ‖ Where do the answers come from? What account do I need? }}

{{ 来自你连接的回答服务。有 ChatGPT 账号可以用 Codex；没有的话，填任意 OpenAI 兼容服务的 API Key，比如 DeepSeek、通义千问、Kimi、OpenRouter，或者本机的 Ollama、LM Studio。 ‖ From the answer engine you connect. With a ChatGPT account you can use Codex; otherwise, add an API key for any OpenAI-compatible service, such as DeepSeek, Qwen, Kimi or OpenRouter, or use Ollama or LM Studio locally. }}

{{ 资料放得很多，回答会不会变慢？ ‖ Will lots of materials slow the answers down? }}

{{ 不会把所有资料塞入上下文。资料先在本机转成结构化文本，回答时按问题检索相关的片段，并标出来自哪份文件、哪一页。 ‖ It doesn’t stuff every file into the prompt. Materials are converted to structured text on your Mac, and each answer pulls only the passages relevant to the question, with the file and page they came from. }}

{{ 有英文界面吗？ ‖ Is there an English interface? }}

{{ 有。在 设置 → 基础 → 语言 切换，切换后 App 会重新打开；少数旧的高级设置页暂时还是中文。建议回答跟着对话的语言走，英文面试就用英文回答。 ‖ Yes.

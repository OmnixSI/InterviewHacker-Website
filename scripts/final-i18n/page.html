{{ 开始使用需要准备什么？ ‖ What do I need to start? }}

{{ 一台 Apple Silicon、macOS 14 及以上的 Mac，以及语音识别 + 对话服务。语音识别默认用本机模型，首次使用下载约 270 MB；回答需要你自己的 Codex（ChatGPT 账户）或任意 OpenAI 兼容 API，按对应服务的规则计费。 ‖ An Apple Silicon Mac on macOS 14 or later, plus speech recognition and an answer engine. Speech runs on a local model by default (a one-time ~270 MB download); answers need your own Codex (ChatGPT account) or any OpenAI-compatible API, billed by that provider. }}

{{ 语音识别可以离线吗？ ‖ Does speech recognition work offline? }}

{{ 可以。默认使用本机 X-ASR 流式识别，再由离线模型整句精修。也可以改用 Apple Speech（需 macOS 26）或云端识别，云端识别需按提示同意后才发送音频。 ‖ Yes. The default is on-device X-ASR streaming with an offline refinement pass. You can switch to Apple Speech (macOS 26) or cloud recognition, which sends audio only after you consent. }}

{{ 资料会全部发给模型吗？ ‖ Is all my material sent to the model? }}

{{ 不会。回答只使用当前问题检索到的资料片段，不会把所有资料塞入上下文；检索不到相关内容时，回答也不会被无关片段限制。 ‖ No. Answers use only the passages retrieved for the current question — never the whole library — and when nothing relevant turns up, unrelated passages don’t constrain the answer. }}

{{ 为什么首次打开提示无法验证开发者？ ‖ Why does macOS say it can’t verify the developer? }}

{{ 当前版本没有 Apple Developer ID 公证。首次打开时在“系统设置 › 隐私与安全性”中选择“仍要打开”即可；更新会校验 SHA-256 与签名。 ‖ The current build isn’t notarised with an Apple Developer ID. On first launch choose “Open Anyway” in System Settings › Privacy & Security; updates verify SHA-256 and signatures. }}

{{ 支持 Intel Mac 或 Windows 吗？ ‖ Is there an Intel Mac or Windows version? }}

{{ 暂不支持。InterviewHacker 是面向 Apple Silicon 的原生 macOS 应用。 ‖ Not at the moment. InterviewHacker is a native macOS app for Apple Silicon. }}

№ 01{{ 一眨眼 ‖ The blink }}

{{ 对方 · 面试官 ‖ Them · the interviewer }}

“{{ 那你为什么想离开上一家公司？ ‖ So why did you leave your last job? }}”

200{{ 毫秒 ‖ ms }}

{{ 一个人说完，到另一个人开口，中间通常只隔两百毫秒左右。研究者比较过十种语言，都差不多。 ‖ Between one person finishing and the next one starting, there are usually about 200 milliseconds. Researchers compared ten languages; it barely changes. }}

600{{ 毫秒 ‖ ms }}

{{ 可从想说什么，到真正说出口，要六百毫秒以上。 ‖ Yet getting from a thought to a spoken word takes 600 milliseconds or more. }}

{{ 所以，人总是在对方还没说完时，就开始想。 ‖ So we start answering before they’ve finished asking. }}

InterviewHacker

{{ InterviewHacker 也这样：对方还在说，它已经在听；话音一落，回答就开始浮上来。 ‖ InterviewHacker works the same way. While they’re still talking, it’s listening. When they stop, the answer starts to surface. }}
